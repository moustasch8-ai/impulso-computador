CRESCIMENTO RESPONSÁVEL

Sem truques.
Sem números inventados.

O Impulso é uma ferramenta de apoio para criadores — não um serviço de venda de seguidores.

✓
Você mantém o controle

Nenhuma ação automática de seguir, curtir, comentar ou reproduzir vídeos é executada.

✓
Confirmações são transparentes

O painel de seguidores é um registro manual, não uma lista oficial fornecida pelo Instagram.

✓
Conexão oficial, quando habilitada

A integração de métricas requer autorização da Meta e uma conta profissional elegível.

✓
Sem prometer resultados

O alcance depende de vários fatores. O Impulso oferece ferramentas e ideias, não garante seguidores ou visualizações.

PERGUNTAS FREQUENTES

O que você precisa
saber.

O Impulso garante novos seguidores?

Não. O Impulso oferece descoberta, desafios e ferramentas para ajudar na criação de conteúdo. O crescimento depende do conteúdo, do público e das decisões de cada criador.

O aplicativo pede minha senha do Instagram?

Não. Quando a conexão oficial estiver disponível, você autorizará o acesso na própria página da Meta/Instagram. Nunca informe sua senha dentro do Impulso.

Os perfis da demonstração são pessoas reais?

Não. Os perfis mostrados na demonstração são exemplos fictícios, usados apenas para apresentar a interface.

O painel de seguidores é sincronizado com o Instagram?

Não. As confirmações são registradas manualmente. A API do Instagram não fornece ao Impulso uma lista de seguidores obtidos especificamente pelo app.

Posso usar no celular?

O site e o painel têm layout responsivo para telas menores. Uma versão Android nativa é um projeto separado.

Onde está o código-fonte?

O projeto é aberto no GitHub. Você pode consultar os arquivos, acompanhar as alterações e ler o guia de instalação no repositório.
